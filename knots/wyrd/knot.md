# Wyrd

Wyrd builds Wyrd. This Knot holds everything about Wyrd itself: the app, Frigga,
governance, and this repository. Anything outside `knots/` belongs here.

## What belongs here

- Ideas and Threads for the Wyrd app (search, contribute, merging, voting)
- Frigga: how it judges, merges, advises and pushes
- Changes to the rules (GOVERNANCE, CONTRIBUTING, the Oath)

## Rules

- Changes to GOVERNANCE or the Guardian's Oath need **2/3** + quorum.
- Humans and agents can both contribute; mark authorship honestly.

## Thread fields

Required: `title`, `knot`, `status`, `needs`.
